# ThinkBoard

ThinkBoard is a full-stack notes application built with the MERN stack. It allows users to create, view, edit, and delete notes through a responsive web interface.

Live Demo: [View ThinkBoard](https://mern-thinkboard-l9js.onrender.com)

The project was built to practice full-stack development, REST APIs, database integration, frontend-backend communication, and API rate limiting.

## Features

- Create, view, edit, and delete notes
- Responsive user interface
- REST API with Express.js
- MongoDB database integration
- API rate limiting with Upstash Redis
- Toast notifications
- Loading and error states
